# Contributing

PlaySparse is measurement-first systems research.

1. Do not claim a savings ratio without a reproducible dataset and benchmark output.
2. Keep original test data read-only.
3. Every experiment must include assumptions, methodology, raw results and a conclusion.
4. Negative results stay in the repository.
5. Do not contribute DRM bypass, anti-cheat bypass, license circumvention or piracy tooling.
6. Prefer small, reviewable experiments over speculative architecture rewrites.

For benchmark changes, include OS, CPU, Zstd version, dataset description, compression level, chunk size, latency percentiles and stored-size ratio.
