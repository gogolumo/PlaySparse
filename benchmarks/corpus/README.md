# Benchmark corpus policy

No copyrighted commercial game assets are committed here.

Corpus classes to build over time:

- compressible structured binary;
- high-entropy/already-compressed data;
- generated texture-like blocks;
- public/open textures and meshes;
- open audio/video assets;
- executable/shader-like generated data;
- repeated data across files;
- version/update simulations with insertion/deletion/replacement;
- open-source game installations where redistribution permits it.

Every result must label its evidence level (L0 synthetic, L1 open, L2 local real game, L3 replicated cross-game).
