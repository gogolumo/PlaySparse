# PlaySparse — Research Collaboration & Engineering Services

PlaySparse is **experimental storage/runtime research**, with an early Tauri desktop app. The current public repository is MIT-licensed; use of the existing open-source code remains governed by that license. This document describes optional paid engineering work, **not a fee for exercising MIT rights**.

## Possible engagements

- Reproducible storage benchmarks and workload profiling.
- Proof-of-concept virtual filesystem or content-addressed storage integrations.
- Rust/Tauri integration and platform packaging assistance.
- Evaluation of compatibility, latency and source-preserving optimization approaches.
- Custom implementation and follow-up maintenance under a written scope.

## Evidence and limitations

PlaySparse does **not** promise arbitrary 10x–15x lossless savings, general game compatibility, reclaimed storage for unchanged originals, or a production-ready mount on all platforms. Feasibility, supported operating systems, filesystem drivers and performance must be validated for each engagement. See [the project status](README.md) and [desktop guide](docs/desktop/README.md).
